# 小说章节自动注入器 · 墨池适配版

二次开发作者：wwj。基于 Molilili001/sillytavern-novel-chapter-injector（原作者菲林 Feilin）0.2.0，保留本地 TXT 功能，新增墨池随机小说片段服务客户端。

## 安装与使用

1. 使用 SillyTavern 1.13.0 或更新版本，在酒馆「扩展 → 安装扩展」中粘贴 `https://github.com/Tsukino-Tsuki/sillytavern-novel-pool-injector`。
2. 刷新酒馆，展开「小说章节自动注入器 · 墨池适配版」。如果安装过原版，先停用原版，避免同名变量与面板重复工作；已有本地小说和设置可沿用。
3. 打开一个角色聊天，选择「远程小说池」。在小说网站登录 Discord、创建令牌链接，再将完整链接粘贴到「令牌或完整链接」。服务地址和链接中的字数会自动填入，也可以分别修改地址、令牌与字数。
4. 在预设需要放入小说参考的位置加入：

```text
{{getvar::current_chapter}}
```

5. 点「获取并注入新片段」可立即查看结果。默认自动模式会在普通生成、重新生成、切换回复及代写前等待新片段到达，再让预设读取；继续生成沿用当前内容。后台 quiet 生成及仅预览提示词的 dryRun 不会请求。

只需安装前端扩展和填写令牌链接。不用修改 config.yaml、不用开启 CORS 代理、不用安装服务器插件或运行系统脚本；小说服务端也不需要增加跨域配置。

## 远程模式行

- `GET /v1/excerpt/{token}?chars=N`，默认 8000，范围 8000～32000。服务端每次随机选小说和起点，可能自然重复。
- 接收 `text/plain`，按服务端的 Unicode 非空白码点口径验证字数；保留片段内部空白与换行。远程片段不再按本地章节设置二次切分。
- 首次失败后最多重试 **3 次**，每次等待 **1 秒**，即总计最多 4 次请求。每次读取含正文的超时为 20 秒，总等待通常不超过约 83 秒。
- 最终失败会提示并保留**当前聊天**的旧内容；当前来源没有旧内容时，明确提示本次不附加小说片段，生成仍可继续。
- 手动模式下仅按钮触发获取。自动与手动模式互斥。连续点击或手动与自动同时触发时，共用同一个在途请求。
- 停止生成、切换聊天或修改远程设置会取消/丢弃原请求，避免把旧请求写到另一个聊天。普通刷新不会自动请求。
- 群聊在实际成员生成前获取，跳过群聊外层调度；自动续写沿用片段。
- 默认正文变量为 `current_chapter`，进度变量为 `current_chapter_index`。远程进度表示当前聊天成功获取次数；两个变量名必须不同。
- 当前片段和来源快照存于聊天元数据，设置存于酒馆用户设置。本地与远程模式来回切换会恢复各自上一次正文和进度。

## 读取方式

默认「酒馆读取」调用酒馆已有的 `POST /api/search/visit`，传入 `{ url, html: false }`；酒馆从服务端获取纯文本并原样返回，浏览器无需跨域访问小说服务。

此接口支持公共域名与 HTTP/HTTPS 标准端口。IP、localhost、私网地址或非标准端口受酒馆限制；自定义站点请提供正常的公共 HTTPS 域名。若自行部署的服务已经支持 CORS，可选「浏览器直连」；默认墨池站点应使用「酒馆读取」。

酒馆读取接口将上游非成功响应统一变成 HTTP 500，插件因此提示检查令牌、资格、网络与服务状态，不能从该通道精确区分小说服务的 401/403/429。浏览器直连可以显示服务端明确的错误代码。

令牌链接只保存在酒馆用户设置中，不发送给模型；片段正文按预设正常发送给模型。酒馆自己的网页读取接口会在服务端日志中记录访问网址，因此完整令牌链接可能出现在**你的酒馆日志**中。分享设置备份、聊天导出或日志前请检查其内容。

## 本地 TXT 模式

保留原版的 UTF-8/GB18030 导入、章节自动识别、按字数切分、批量注入、目录跳转、自动推进与循环模式。导入完成即注入第一段，之后生成结束再推进下一段；本地与远程的推进时机不同。

本地全文及章节通过酒馆提供的 localforage 保存；进度按聊天保存。不要在预设中再用 `{{setvar::current_chapter::...}}` 覆盖正文变量。

## 开发与验证

```text
npm test
```

运行测试不需要安装 npm 依赖。测试覆盖 URL/字数校验、纯文本解析、重试、取消、生成时机、去重、聊天隔离和来源恢复。

浏览器集成脚本 `tests/browser-integration.cjs` 需 Playwright 和独立的 SillyTavern 测试实例；默认端口 8899。它创建合成测试角色，对小说读取使用合成正文，并额外通过真实酒馆接口读取 RFC 公共文本验证默认通道。不应直接在个人日常酒馆上运行测试脚本。

源码兼容性核对：SillyTavern 1.13.0 tag 与 1.19.0 release；实际浏览器验证在 1.19.0 上完成。未使用真实小说访问令牌或付费模型进行端到端生成验收。
